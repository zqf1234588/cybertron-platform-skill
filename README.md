# 联想万全平台操作 Skill

面向**联想万全异构智算平台（Cybertron）**的中文 agent 操作指南，覆盖文件管理、在线开发、工具服务和 PyTorch 训练任务。它将已确认的界面操作整理为可按需读取的知识，帮助 agent 从当前页面直接完成目标。

## 为什么需要这个 skill

平台功能分布在多个菜单、列表和详情页中。若每次都从头探索，agent 会重复读取页面、尝试入口，也需要用户反复解释项目选择、资源核算和日志查看方式。

这个 skill 保存通用的操作路径和关键判断：从哪里进入、应读取哪些字段、何时需要查看另一页面，以及怎样确认操作完成。目标是**减少走弯路、重复工具调用和无关上下文加载**，让额度尽量用于完成任务。实际节省量取决于任务和界面状态，不承诺固定比例。

它是操作知识，不是训练脚本或平台接口；仍需要具备相应权限的浏览器操作工具。

## 如何组织

```text
SKILL.md                         目标索引与通用规则
references/
├─ navigation.md                 完整界面层级，按需读取
├─ workspace/
│  ├─ files.md                   文件管理
│  ├─ online-development/        创建、启动、打开、保存镜像
│  └─ tool-services/             SFTP 与 TensorBoard 服务
├─ training/
│  ├─ templates/pytorch/         创建训练任务
│  └─ tasks/                     列表、摘要、监控、日志、终端
└─ apps/
   └─ tensorboard.md             指标查看、筛选与刷新
```

目录按界面归属组织，但操作关系不局限于树：

- **强连接**：通过明确控件直接跳到另一个页面，记录方向和前提。
- **弱连接**：完成当前目标时可能需要的辅助信息，注明触发条件。
- **完成判据**：说明何时已经获得所需结果，避免继续做无关检查。

日常使用从 [SKILL.md](SKILL.md) 直接找到目标文档，不必先遍历[导航图](references/navigation.md)，也不默认读取全部文件。未验证的流程保持留空，界面变化时以当前页面为准。

## 使用方式

将本仓库的 `SKILL.md` 与 `references/` 放入 Codex 的 `skills/cybertron-platform/` 目录。提出任务时提供目标平台和必要参数，agent 根据入口索引读取对应步骤。

## 内容与隐私边界

只保存通用操作与不含身份信息的约定。真实账户、密码、令牌、项目名称/ID/路径、私有镜像、门户实例地址和账户配额不写入仓库；具体参数由当次任务提供。

具体问题保存在独立的 **debug 记录**中，项目参数和实验协议保存在独立的**笔记**中；整理后只有确认通用的操作经验才补回 skill。原始备份、debug 记录和项目笔记不随仓库发布。
