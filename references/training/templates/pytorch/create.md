# 创建 PyTorch 任务

入口：训练 → 任务模板 → PyTorch → 创建任务。来源：用户教学及提交实测。

## 操作

1. 执行入口全局项目、命名和资源规则。复用现有表单；核对[任务列表](../../tasks/index.md)是否已有同一提交。
2. 依次填写：基本信息 → 资源配置 → 运行配置 → 高级配置。

| 阶段 | 已知设置 |
| --- | --- |
| 基本信息 | 名称、项目遵循全局规则；镜像、启动目录、完整命令及模型/数据集等参数由本次任务提供 |
| 资源 | 按任务需求选择部署类型、GPU 类型/数量、CPU 和主存，核对当前可用额度与自动显示的显存 |
| 运行 | 作业优先级“正常” |
| 高级 | 实测“断点续训”开关禁用；恢复依赖程序显式 load/save，不能把开关当作恢复保证 |

3. 命令保留真实换行，在前台运行；不加 `nohup` 或末尾 `&`，让平台采集日志、管理生命周期。
4. 核对名称、项目、镜像、完整命令、资源；在已授权提交范围内点击一次“提交”。

**完成判据**：列表出现准确名称及状态。排队表示提交成功，实际训练启动需查看 worker 日志。响应不明先查列表，不重复提交。

**跳转**：“提交”成功 → [任务列表](../../tasks/index.md)（实测）。
