# 任务列表

入口：训练 → 任务管理；已观察路由 `#/tasks/task-management`。来源：实测。

1. 等待表格加载，按准确任务名定位；找不到时检查“已完成/未完成”筛选与分页。
2. 核对项目、模板、提交时间和状态；详情中补查资源。不要把暂时空表判为任务丢失。
3. 需要详情时打开目标任务。

**完成判据**：找到匹配的任务并确认所需状态。排队 ≠ 训练启动，运行中 ≠ 训练成功。

**跳转**：目标任务入口 → [摘要](summary.md)；任务详情侧栏“摘要/监控/日志/终端”可切换同一任务下的四页。

**辅助**：确认训练是否推进 → [日志](logs.md)；仅查看状态无需加载其他详情文档。
