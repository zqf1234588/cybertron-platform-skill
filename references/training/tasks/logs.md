# Worker 日志

入口：任务详情“日志”或实例行“查看日志”。来源：用户教学及刷新实测。

1. **实例列表 → 目标 worker**（单实例通常 `worker-0`）；选择后再读取。未选择时“无数据”和下载禁用不能说明训练失败。
2. 需要最新输出时点击行数旁刷新按钮；页面重载后可能丢失实例选择，重新选择 worker。
3. “行数”（示例 500）只控制当前显示量，不代表完整历史。按实际输出区分 train/validation、epoch、batch、速度和 metric。
4. 需要保存完整日志时点击右上角带下载图标的“日志”，确认文件实际下载完成。

**完成判据**：拿到目标实例所需时段的输出，或确认日志文件已下载。仅有 `Train 1/30` 不足以判定 fold；未明确打印的字段不猜测。

**跳转**：详情侧栏 → [摘要](summary.md)、[监控](monitor.md)、[终端](terminal.md)。

**辅助**：要核对曲线与输出是否对应 → [TensorBoard 应用](../../apps/tensorboard.md)。
