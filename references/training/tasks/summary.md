# 任务摘要

入口：任务管理 → 目标任务 → 摘要。来源：用户教学。

| 区域 | 可核对信息 |
| --- | --- |
| 基本信息 | 名称、项目、状态、提交/开始/结束时间、运行时长、类型、优先级、“更多操作” |
| 展开更多详情 | 运行程序、任务 ID、CPU/主存/GPU 配置、镜像、创建者、root、自动清理、模板、MPS、部署类型 |
| 实例表 | worker 名称、状态、资源、创建时间、运行时长；“查看日志”“终端” |

读取完整字段，截断文本不能当作完整命令。任务级和实例级状态分别核对；自动清理时间及范围不从历史截图推定。

**完成判据**：目标任务身份与所需配置/生命周期字段已核实。

**跳转**：实例行“查看日志” → [日志](logs.md)；“终端” → [终端](terminal.md)；侧栏“监控” → [监控](monitor.md)。
