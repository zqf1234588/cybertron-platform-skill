# 工具服务列表

入口：工作空间 → 工具服务。来源：用户教学。

按类型、目标项目和目标用途定位服务卡片，读取状态、镜像、地址；TensorBoard 另有日志目录。先复用匹配服务，避免重复创建。列表“启动/停止”会改变运行状态、资源占用，查看请求不点击。

**完成判据**：确定所需服务及其状态、地址或配置；截图值不当作实时状态。

**跳转**：左上圆圈加号（刷新旁） → [创建服务](create.md)；TensorBoard 卡片服务地址 → [TensorBoard 应用](../../apps/tensorboard.md)。

**辅助**：查看完整服务信息 → [SFTP 摘要](sftp.md)或[TensorBoard 摘要](tensorboard.md)；摘要入口具体点击方式以当前页面为准。
