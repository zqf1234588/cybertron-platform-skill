# 创建工具服务

入口：工具服务列表左上圆圈加号；不要点 SFTP 表单内部的 PVC 加号。来源：用户教学，尚未实测提交。

先按全局规则核算资源，选择工具类型和目标项目，再填对应字段。

| 字段 | SFTP | TensorBoard |
| --- | --- | --- |
| 服务镜像 | 选择当前平台提供的 SFTP 镜像 | 选择当前平台提供的 TensorBoard 镜像 |
| 必需输入 | 密码；用户名由平台填入 | 日志目录（右侧文件夹选择器） |
| 其他 | PVC 挂载；空闲超时默认 30 分钟 | 使用已核实的事件日志目录 |
| 资源 | 核对实际 CPU / 主存申请 | 核对实际 CPU / 主存 / GPU 申请 |

SFTP 用户名由平台填入，以当前界面为准，不记录真实账户值。密码不猜测、不写入 skill。PVC 选择挂载、目录选择器内部流程未教学，读取实际界面；不能猜路径。已有 SFTP 的 1 小时超时不代表新建默认值。

在创建已获授权且必填项完整时提交一次；结果不明确先查列表。

**完成判据**：列表中目标服务及状态得到确认。提交后自动跳转未实测。

**辅助**：核对结果 → [服务列表](index.md)。
