# 在线开发

入口：工作空间 → 在线开发；已观察路由 `#/workspace/online-dev-env`。来源：用户教学。

## 启动与打开

定位目标卡片，核对项目、类型、镜像、CPU/主存/GPU 配置及状态。按全局规则核算资源，点击“启动”，等待运行且“打开”可用，再点击“打开”。当前主要是 Notebook/Jupyter，也可能是其他开发应用。

**完成判据**：目标环境实际运行，且开发页面可访问；不重复启动或另建同名环境。

## 保存与另存为镜像

临时安装库和环境配置重启后会丢失；需保留时，**运行期间**点击“更多 → 保存/另存为”。关机时这两个入口禁用。后续名称、版本、覆盖范围和确认流程未教学，执行时读取实际表单；完成以镜像保存结果为准。

环境镜像、持久挂载的项目文件、训练 checkpoint 是不同对象；不推断保存镜像会保存全部项目数据。

**跳转**：左上圆圈加号 → [创建环境](create.md)；运行环境“打开” → 开发应用；“更多 → 保存/另存为” → 镜像保存流程（内部留空）。
