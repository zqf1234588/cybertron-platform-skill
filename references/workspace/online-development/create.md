# 创建在线开发环境

入口：在线开发列表左上圆圈加号。来源：界面教学；未实测创建。具体配置由当前任务提供。

| 字段 | 填写规则 |
| --- | --- |
| 类型 | Notebook（当前主要 Jupyter） |
| 名称、项目 | 入口全局规则 |
| 运行环境 | 选择本次任务指定且可访问的镜像 |
| CPU / 主存 | 按本次需求及可用额度申请 |
| GPU | 按需求选择类型、数量，核对自动显示的显存 |
| root | 按本次任务需要及授权设置 |
| 密码 | 截图空；不推断必填性，不猜测或保存密码 |
| 空闲超时 / 优先级 | 按本次任务要求设置 |

名称 1–32 字符，只含小写字母、数字、短横线；小写字母开头、字母或数字结尾。先核对资源余量再提交；默认配置不是可用额度。

**完成判据**：列表出现目标环境，状态已核对；提交成功不等于可以打开。

**辅助**：创建后需启动/打开 → [在线开发](index.md)。提交后的自动跳转未实测。
