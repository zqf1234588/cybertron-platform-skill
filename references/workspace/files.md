# 文件管理

入口：工作空间 → 文件管理；已观察路由 `#/workspace/file-management`。来源：用户教学及目录导航实测。

1. 左侧“项目目录” → 目标项目 → 目标目录；个人文件另在“我的文件”。
2. 展开目录树，或双击右侧文件夹进入；等待列表更新，再核对底部面包屑、路径提示与文件名。
3. 按需要读取名称、权限、修改时间、大小、类别。搜索仅针对当前视图，不是递归搜索。

工具栏有后退、前进、刷新、新建文件夹、删除、上传、下载、排序、图标视图。文件右键可见打开/下载/删除，但**点击“打开”不等于已读到内容**；未见预览或下载结果时保留“尚未读取”的结论。

**完成判据**：目标绝对路径和所需目录/文件信息已核对。只读请求停在此处。

**跳转**：目录树或右侧文件夹 → 子目录；后退/前进 → 浏览历史目录。

**辅助**：结合训练输出判断产物所属阶段 → [worker 日志](../training/tasks/logs.md)。
